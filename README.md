# Héctor Rivera — Portfolio

Personal portfolio site: experience timeline, project cards, and a design gallery.

## Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- CSS Modules

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```
